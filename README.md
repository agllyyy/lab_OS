## Описание

Программа выполняет многопоточное умножение матриц со статическим распределением строк между потоками. Строки результирующей матрицы делятся непрерывными блоками, остаток добавляется последнему потоку.

**Возможности:**
- Статическое распределение строк (непрерывные блоки)
- Отображение прогресса выполнения в процентах
- Замер времени выполнения и контрольная сумма
- Юнит-тесты (7 тестов) для проверки корректности

## Требования

- .NET 9.0 или выше
- Visual Studio 2022 / VS Code / любой редактор с .NET SDK
- Windows 10/11, Linux или macOS

## Сборка и запуск

### Запуск программы
```bash
dotnet run -c Release --project LabOS
```
*(Параметры можно передать аргументами, например: `dotnet run -c Release --project LabOS -- 500 500 500 4`, либо ввести интерактивно в консоли).*

### Запуск юнит-тестов
```bash
dotnet test
```
